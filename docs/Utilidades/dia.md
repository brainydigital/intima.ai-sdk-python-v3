# Utilidade: **Dia**

Você pode utilizar a constante de dia para melhor legibilidade do seu código, por exemplo:

```python
from intimai.utilidades.dia import Dia

dia = Dia.SEGUNDA_FEIRA
```

Abaixo, está a tabela com todos os valores possíveis para a constante de dia.

Constante | Valor
------------ | -------------
DOMINGO | 0
SEGUNDA_FEIRA | 1
TERCA_FEIRA | 2
QUARTA_FEIRA | 3
QUINTA_FEIRA | 4
SEXTA_FEIRA | 5
SABADO | 6
