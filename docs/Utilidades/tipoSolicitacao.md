# Utilidade: **Tipo Solicitação**

Você pode utilizar a constante de tipo solicitação para melhor legibilidade do seu código, por exemplo:

```python
from intimai.utilidades.tipo_solicitacao import TipoSolicitacao

tipo_solicitacao = TipoSolicitacao.HABILITACAO_SIMPLES
```
