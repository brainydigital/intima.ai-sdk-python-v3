# Utilidade: **Ação**

Você pode utilizar a constante de ação para melhor legibilidade do seu código, por exemplo:

```python
from intimai.utilidades.acao import Acao

tipo_acao = Acao.TIPO_INFORMACAO
```

Abaixo, está a tabela com todos os valores possíveis para a constante de ação.

Constante | Valor
------------ | -------------
TIPO_INFORMACAO | 0
TIPO_COPIA | 1
TIPO_INTIMACAO | 2
TIPO_ESCUTA | 3
TIPO_PROTOCOLO | 4
TIPO_PROTOCOLO_HABILITACAO | 5
TIPO_ANDAMENTO | 6
TIPO_CONSULTA | 7
TIPO_PRE_CONSULTA | 8
